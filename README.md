# 公仆之路 · 公务员职业生涯模拟

## 打开方式（重要）
**直接用浏览器打开 `index.html` 即可。**（就一个文件，无外部依赖）
- 更新版本后首次打开会提示"检测到游戏文件被修改"，这是完整性校验的正常反应。
- 点 **🔒 维护者入口 · 重新锚定**，输入维护密码后即可重新锚定基线（连错 3 次锁定本次会话）。
- 维护密码**不写在任何文件里**：游戏内只保存 fnv1a 指纹，打包脚本只保存 sha256 指纹。密码由项目所有者掌握；忘记或要更换，让 Eta 重算指纹即可。

## 专业模式：准入机制
1. 开局页选 **专业模式** → 点【入职报到】
2. 弹出一道随机真题（单选），选项与解析都在弹窗里
3. **答对**：显示参考答案与解析 → 点【进入专业模式】直接开局，顶栏会带"专业模式"标记，台账记一条准入通过
4. **答错**：显示你选的、参考答案、解析 → 专业模式记为**锁定**；回到开局页后再点专业模式会被拦回普通模式并提示原因
5. **解锁**：普通模式走到"履职生涯圆满"（晋升到一级巡视员）时自动解锁，之后选专业模式可直接进入

### 题库来源与诚实说明
- 题目取自 **2025年国家公务员考试《行政职业能力测验》（地市卷）回忆版真题**，转载页：爱真题 `https://www.aipta.com/article/10375.html`（2026-10-15 取用）。
- **国考官方从不公布真题与标准答案**，市面上的"真题"都是机构回忆版；该转载页的答案需付费下载，本次未取得。
- 因此游戏里的**参考答案与解析由本项目整理**（题目原文照录，答案按法律条文、学科常识判定），仅用于游戏内准入，**不作备考依据**。
- 目前入库 16 题，覆盖政治理论、法律（党纪/行政复议/公司法/物权）、历史与科学常识。想加题就往 `js/法条数据.js` 的 `EXAM_BANK` 里加对象，字段：`src / q / opts[4] / a(0-3) / exp`。

## 专业模式：和普通模式的差别（都在这里，普通模式一律不受影响）
| 维度 | 普通模式 | 专业模式 |
|---|---|---|
| 准入 | 无 | 先答一道历年真题（限时120秒），答错锁定、普通模式通关后解锁 |
| 险情处置门槛 | 统一 40（宽松） | 基准 45/42/36/55 ×（1 + 职龄×5%，上限 ×1.6）——**职龄越长越吃力** |
| 法规查阅 | 开放 | **关闭**（按钮隐藏，函数也拦） |
| 突发事件池 | 基础 51 个 | 基础池 + **8 个专属事件**（更迷惑的选项、更现实的处分） |
| 被查处概率 | 基准 | ×1.15 |
| 从轻条件 | 当季廉政建设投入 ≥4 即可减轻 | 需 ≥6，且只降一档 |
| 处分档次 | 政务处分（警告/记过/记大过/降级/撤职/开除） | 另加组织处理（批评教育/诫勉/通报批评/调离岗位）与党纪处分（党内警告/严重警告/撤销党内职务/留党察看），各带真实影响期 |
| 险情频率/时限 | 1.0/季度，22s 起 | 1.5/季度，18s 起 |

## 地图险情机制
- **按真实时间随机出现**（不再卡季度开头）：期望值 = `incident.perQuarter`（普通 1.0 / 专业 1.5）÷ 季度秒数，每真实秒判定一次；同时最多 3 处。
- **处置门槛与"应急能力"条子挂钩**：普通模式统一 40；专业模式 = 基准 ×（1 + 每年 5%，上限 ×1.6）。不达标就点不动，提示"处置力量不足"，只能看它超时。
- 处置时限 = `lifeBase + 应急能力×0.12s`（普通 22s 起，专业 18s 起），应急能力越高越扛得住。
- 及时处置：应急 +2.5、满意 +1.5、公信 +1；超时未处置：应急 −5、满意 −3、公信 −2，并记违纪台账。
- 提前结算不能躲：季度结束时未处置的险情按"处置不及时"结算。

## 修改游戏的方法
1. 编辑 `js/` 里对应的 `.js` 文件
2. 运行 `sh 重建.sh` 重新生成 index.html —— **需要维护密码**（指纹校验，密码不写在脚本里）
3. 打开游戏 → 点【🔒 维护者入口】→ 输入同一个维护密码 → 重新锚定

## 防篡改说明（诚实版）
- 启动器是唯一执行入口；两道防线：启动器指纹校验 + 引擎内 900ms 后独立复核基线。
- 重锚入口需维护密码，连错 3 次锁定本次会话。
- 物理上限：纯前端无服务端，两处一起重写仍可绕过；防的是"随手改数值/删文件"级别。

## 待你继续定的（专业模式玩法）
目前专业模式只是"参数更严"，还没定独有玩法。可扩展的挂点已经留好：
- `GP_MODES.pro.overrides`：数值型难度（年限、频率、奖惩幅度、初始指标）

- `POSTS` / `EVENTS` / `RANKS` / `BUILDS`：整块替换成更专业的数据集
- 若要做"专业模式专属规则"（例如更细的财政与编制约束、更严的考察程序、任期审计），告诉我规则我来加。
